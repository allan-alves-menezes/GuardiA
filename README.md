# GuardiA
Sistema corporativo de cibersegurança em tempo real. Desenvolvido em C# (.NET 10 API) e Blazor Server, possui painel admin em tema escuro, monitoramento de alvos HTTP, auditoria de senhas vazadas via k-Anonymity, detector de e-mail spoofing (SPF/DKIM/DMARC) e gerador de typosquatting para proteção de marcas.
